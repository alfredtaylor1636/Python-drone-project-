
This project uses Python to control a CoDrone EDU drone and collect flight data in real time. The program records flight time, speed, acceleration, altitude, and other information. It also detects crashes and prevents practice or crashed flights from being added to the leaderboard. The flight results are stored using classes and a minimum heap, which ranks the pilots by their flight time.


このプロジェクトでは、Pythonを使ってCoDrone EDUのドローンを操作し、リアルタイムで飛行データを収集します。飛行時間、速度、加速度、高度などのデータを記録します。また、墜落を検知して、練習飛行や墜落した飛行をランキングに入れないようにしています。クラスと最小ヒープを使って飛行結果を保存し、飛行時間が速い順にランキングします。
